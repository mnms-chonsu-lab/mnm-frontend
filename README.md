# mnm-frontend

촌수의사 — 농가 앱(모바일 반응형 웹앱)·접수자 웹·어드민 프론트엔드.

## 폴더 구조

```
mnm-frontend/
├── apps/
│   ├── farmer-app/     # 농가 앱
│   ├── receiver-web/   # 접수자 웹
│   └── admin/          # 어드민
├── packages/
│   ├── ui/             # 공통 디자인 토큰·컴포넌트
│   ├── mocks/          # 가짜 데이터 (API 연동 전 화면 작업용)
│   └── api-client/     # API 호출·타입
├── docs/               # 결정 기록
└── .github/            # 이슈·PR 템플릿, CODEOWNERS, 라벨
```
